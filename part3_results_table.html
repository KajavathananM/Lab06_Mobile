Comparison of UI Isolate vs. Isolate.run for JSON parsing benchmarks

Mode Dataset Size (n) End-to-End Fetch Decode Worst Frame Est. Dropped Spinner Behavior
UI Isolate 5,000 (5k) 180 ms 130 ms 45 ms 50.0 ms 2 - 3 Minor stutter
Isolate.run 5,000 (5k) 185 ms 130 ms 48 ms 16.6 ms 0 Smooth rotation

Isolate.run 50,000 (50k) 870 ms 400 ms 450 ms 16.6 ms 0 Smooth rotation
Key Finding: At n = 50,000, parsing on the UI Isolate blocks the main thread for ~430 ms, causing severe jank (25+ dropped frames). Using Isolate.run offloads parsing to a worker isolate, resulting in 0 dropped frames and continuous 60 FPS animation.
