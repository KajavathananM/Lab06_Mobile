Analysis of Isolate.run performance impact and trade-offs

1. Metrics Improved:

Isolate.run significantly improved UI frame metrics—reducing estimated dropped frames to 0 and worst frame render time to 16.6 ms (60 FPS)—because CPU-heavy JSON parsing was offloaded from the main UI thread.

2. Metrics Not Improved & Why:

However, it did not improve actual decode time or end-to-end total time due to the CPU workload remaining identical alongside a small isolate spawning and memory-transfer overhead.

3. Value at n = 5k:

At n = 5k, decoding only takes ~45 ms causing minimal frame drops (2–3), making the isolate overhead barely worth it compared to n = 50k where offloading is essential to prevent a complete half-second UI freeze.
